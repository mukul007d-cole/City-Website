🕌 Ajmer Tourism Website — Winner of the Identity Exhibition 2023 🏆
A beautifully crafted tourism web experience dedicated to the historic city of Ajmer, Rajasthan. This project brings together rich cultural heritage, stunning visuals, and essential travel information — all wrapped in a responsive and interactive UI.

🥇 Awarded Best Web Project at the Identity Exhibition 2025


🌟 Highlights
🕌 Explore Ajmer’s iconic landmarks like Dargah Sharif, Ana Sagar Lake, Taragarh Fort, and more

🧭 Interactive maps and travel tips

🎨 Visually appealing and responsive UI for all screen sizes

🕰️ Timeline of Ajmer’s rich cultural history

📸 Integrated gallery and media section

🧳 Built with love for promoting local tourism
